# Análisis de fútbol
## Sobre el proyecto
Este proyecto analizará la información sobre goles de los equipos de fútbol masculino de primer nivel en el Reino Unido, Italia y España. Estas son la Premier League, la Serie A y La Liga, respectivamente. Examinaremos las tendencias de puntuación de los últimos cinco años y las compararemos entre las tres ligas.

**Créditos: [Kaggle: Puntuaciones de los partidos de las últimas 5 temporadas de las 5 grandes ligas de Europa](https://www.kaggle.com/datasets/ufukckose/top-5-european-football-leagues-match-results-data)**
